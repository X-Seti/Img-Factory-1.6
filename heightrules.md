# X-Seti - October 22 2026 - IMG Factory 1.6 - UI height rules

# Height Rules

Same sizes in every workshop and IMG Factory itself.
"Rule" is the size to use. "Now" is what Map Workshop uses today.

| Element | Rule | Icon | Now (Map Workshop) |
|---|---|---|---|
| Dock title bar | 26 px | - | 26 px (24 measured) |
| Dock title bar buttons | 22 x 22 px | 16 px | 22 x 22, icon 16 |
| Toggles in a title bar | 20 px | 16 px | 18-20 px |
| Main action buttons (Load, Apply, Pick, OK, Cancel, Reset) | 26 px | 18 px | 26 px |
| Small row buttons (open, new, delete, save, Recent) | 18 px | 16 px | 18 px, icon 18 |
| Overlay buttons (Render, IPL mode) | 18 px | - | 18 px |
| Toolbar icon buttons (left and top) | 28 x 28 px | 20 px | 27-28 px, icon 18-20 |
| Small custom widgets (gauges) | 22 px | - | 20-22 px |
| Search box | 26 px | - | 26 px |
| Line edits | 24 px | - | 23-26 px |
| Combo boxes | 24 px | - | 26 px |
| Spin boxes, time edits | 24 px | - | 24 px |
| Checkbox | 18 px | - | 18 px |
| Labels (next to inputs) | 24 px | - | 22-25 px |
| Table headers | 26 px | - | 26 px (some 16) |
| Table rows, text | 20 px | - | 16 px |
| Table rows, icon | icon + 4 px | 32 / 48 / 64 | 52 (icon 32), 30 (icon 64) |
| Picker grid tiles | 48 or 64 px | - | - |
| Tab bar | 22 px | 16 px | 20 px |
| Status bar | 22 px | - | 22 px |

## Layout
- Input rows: label right-aligned, vertically centred, 2 px spacing.
- Spin box text padding: 0px 4px.
- Number fields 80 px wide; labels as wide as the longest label.
- No bar over 26 px.
- Icon-only buttons need a tooltip.
- Space is limited: icons instead of text where a tooltip can explain.
